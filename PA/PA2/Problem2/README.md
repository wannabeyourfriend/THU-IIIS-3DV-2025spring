## 1. (3D losses) 

Let $P$ and $Q$ be two finite sets of points in 3D space, namely $P = \{p_i\}_{i=0}^{n-1}$ and $Q = \{q_j\}_{j=0}^{m-1}$ where $p_i, q_j \in \mathbb{R}^3$. We use $d(p_i, q_j) = \|p_i - q_j\|_2$ to represent the Euclidean distance between $p_i$ and $q_j$. The Hausdorff Distance between $P$ and $Q$ is defined as

$$h(P,Q) = \max\{d(P,Q), d(Q,P)\},$$

where $d(P,Q) = \max_{p_i \in P} [\min_{q_j \in Q} d(p_i, q_j)]$ and $d(Q,P) = \max_{q_j \in Q} [\min_{p_i \in P} d(q_j, p_i)]$.

**[Programming Assignment]** Implement Hausdorff Distance (HD) loss and Chamfer Distance (CD) loss in python. The implementation of these two losses should be differentiable for network training.
